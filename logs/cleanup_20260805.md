# 이미지 중복 사용 버그 수정 (2026-08-05)

> 이 작업은 이전 AdSense 도어웨이/중복 콘텐츠 정리(`logs/cleanup_20260804.md`, STEP 0-4)와
> **별개 이슈**입니다. 별도 커밋/로그로 관리하며, STEP 4 리다이렉트 작업과 섞지 않습니다.

## 1. 문제 신고

일부 아티클에서 서로 다른 장소/섹션인데 동일한 Unsplash 이미지가 반복 노출됨
(본문 섹션 이미지 캐러셀 + 추천 장소 PlaceCard 양쪽에서 발생).

## 2. 원인 진단

전수조사 결과 두 개의 독립된 버그를 확인 (`reports/duplicate_images_full.csv`, 161건):

### 버그 A — 본문 섹션(`###` 아이템) 이미지 캐러셀
- 위치: `src/lib/unsplash.ts`의 `itemToSearchQuery()` / `fetchItemImages()`
- 원인:
  1. `itemToSearchQuery()`의 정규식(`/쇼핑|시장|shopping|market/` 등)이 서로 다른 소제목을
     동일한 검색어로 뭉개버림 (예: "펑지아 야시장"과 "쇼핑 명소"가 모두 "Taichung shopping market"로 매핑)
  2. `fetchItemImages()`에 페이지 내 아이템 간 중복 방지(dedup) 로직이 전혀 없음
  3. `page=1` 고정 → 동일 검색어는 항상 동일한 최상위 결과 이미지 반환
- 영향: 124개 아티클, 160건의 쿼리 충돌 케이스
- 참고: `## ` 아이템리스(item-less) 섹션(`sectionImageResolver.ts`/`smartImageSearch.ts`,
  DB 캐시 기반)은 이미 정상적인 `usedUrls` dedup을 갖추고 있어 버그 대상 아님 — 수정하지 않음

### 버그 B — 추천 장소(PlaceCard) 카드 이미지
- 위치: `src/components/article/PlaceCard.tsx` (기존 버전)
- 원인: 장소별로 각각 독립적으로 `fetchUnsplashPhoto(per_page=1)` 호출, 페이지 내
  카드 간 중복 방지 로직 없음
- 재현: `taipei-shopping-guide-ko` 아티클에서 "타이베이 101 쇼핑몰" / "스린 야시장" /
  "라오허제 야시장" 3곳이 모두 동일 이미지(`photo-1598935898639`)로 표시되는 것을
  실제 Unsplash API curl 호출로 재현 확인
- 랜덤 샘플링(1차 22건, 2차 27건)에서는 충돌 미검출 — 명소 위주 샘플이라 사진이 풍부한
  케이스만 뽑힌 표본 편향으로 판단, 실제 신고 사례(야시장류 소규모 장소)를 직접 재현하여 확정

## 3. 수정 방향 (승인: "지정하신 대로 완전 제거 (원안)")

- 본문 섹션 캐러셀(`###` 아이템 이미지)은 **완전 제거**. 대상 아티클(240/253)은
  이미지 없이 텍스트만 노출 — 이미지 없음이 중복 이미지보다 낫다는 원칙 적용.
- PlaceCard는 **페이지 단위 배치(batch) 중복 제거**로 수정. 후보 이미지 여러 장(5장) 조회 후
  이미 사용된 URL을 제외한 첫 번째 고유 이미지를 사용. 고유 후보가 없으면 이미지 없이
  플레이스홀더 아이콘 표시 (다른 장소의 사진을 재사용하지 않음).

## 4. 실제 변경 사항

- `src/lib/unsplash.ts`: `itemToSearchQuery()`, `fetchItemImages()` 삭제
- `src/components/ui/ImageCarousel.tsx`: 삭제 (더 이상 사용되지 않음)
- `src/components/article/PlaceCard.tsx`: 전면 재작성
  - `resolvePlaceImages(places, city)` — 페이지 단위 배치 dedup 함수 신설
    (기존 `image_url` 보유 장소를 우선 신뢰 → usedUrls에 등록 → 나머지 장소는
    후보 5장 중 미사용 이미지 선택 → 없으면 `null`)
  - `PlaceCard` 컴포넌트는 순수 동기 컴포넌트로 전환, `imageUrl` prop을 그대로 렌더링
- `src/app/article/[slug]/page.tsx`:
  - `fetchItemImages`/`itemToSearchQuery` import 제거, `ImageCarousel` 렌더링 제거
  - `resolvePlaceImages(places, article.city)` 호출 후 `placeImages[place.id]`를 `PlaceCard`에 전달
  - `###` 아이템은 캐러셀 없이 제목+본문 HTML만 렌더링
- `src/app/en/article/[slug]/page.tsx`: 위와 동일한 패턴 적용 (KO 버전과 미러링)
